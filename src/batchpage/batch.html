Batch collection

Collect many jobs at once from authorized sources only: a company's public Greenhouse job board (official API) or a CSV/JSON file you provide. This does not crawl LinkedIn. Jobs are saved to your private profile as the run goes, so a pause, stop or interruption never loses finished work.

No email or password: your saved jobs are tied to this extension's data in this browser. If that data is cleared or the extension is removed, they cannot be recovered.

1. Source

The token is the last part of a company's Greenhouse job-board address (for example boards.greenhouse.io/figma). Up to 10 boards. Data comes from Greenhouse's public Job Board API (documentation); each saved job keeps its original posting link. Only use boards you are allowed to read.

Needs a title and an https URL per job. Optional: company, location, description, posted date, salary, employment type, remote, skills, experience, status, id. Any HTML is converted to plain text. Re-importing the same file is safe: existing jobs are updated, never duplicated, and empty optional fields never erase values already saved. Full format: docs/IMPORT_FORMAT.md in the extension folder.

2. Limits

Hard limits: 500 jobs, 50 pages, 50 per page.
